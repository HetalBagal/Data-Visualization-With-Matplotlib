# Data-Visualization-With-Matplotlib
This project demonstrates basic data visualization techniques using Matplotlib and Pandas in Python. It includes different types of plots and a simple sales data analysis.

⚙️ Requirements

Install required libraries:

pip install matplotlib pandas numpy
📈 Features
Line Plot (basic & customized)
Multiple Subplots
Bar Chart
Histogram
Scatter Plot
Pie Chart
Sales Data Visualization using Pandas
📊 Dataset

The project uses a sample sales dataset containing:

Customer ID
Product Category
Quantity
Price per Unit
Total Amount
