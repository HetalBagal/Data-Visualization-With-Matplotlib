# Data-Visualization-With-Matplotlib
This project demonstrates basic data visualization techniques using Matplotlib and Pandas in Python. It includes different types of plots and a simple sales data analysis.

⚙️ Requirements

Install required libraries:

pip install matplotlib pandas numpy<br>

📈 Features<br>

Line Plot (basic & customized)<br>
Multiple Subplots<br>
Bar Chart<br>
Histogram<br>
Scatter Plot<br>
Pie Chart<br>
Sales Data Visualization using Pandas<br>

📊 Dataset<br>

The project uses a sample sales dataset containing:<br>

Customer ID<br>
Product Category<br>
Quantity<br>
Price per Unit<br>
Total Amount<br>

💡 Example<br>

import matplotlib.pyplot as plt<br>

x = [1,2,3,4,5]<br>
y = [1,4,9,16,25]<br>

plt.plot(x, y)<br>
plt.xlabel("X Axis")<br>
plt.ylabel("Y Axis")<br>
plt.title("Basic Line Plot")<br>
plt.show()<br>

🎯 Conclusion<br>

This project helps understand how to visualize data and extract insights using Python.
